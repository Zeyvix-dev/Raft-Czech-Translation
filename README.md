# 🇨🇿 Český překlad hry Raft

**Český překlad hry Raft ve formě samostatného modu.**

Užij si dobrodružství na moři v češtině! Mod při spuštění automaticky načte český překlad.

[![RaftModding](https://img.shields.io/badge/RaftModding-Instalovat%20mod-28a745)](https://www.raftmodding.com/mods/raft-czech-translation)
[![Verze](https://img.shields.io/badge/verze-1.0.0-blue)](https://github.com/zamazallukas02-spec/Raft-Czech-Translation/releases/latest)

## ✨ Funkce

- Český překlad hry Raft.
- Automatické načtení překladu při spuštění modu.
- Obsahuje překladová data a zdrojový kód modu.
- Projekt vytvořený pro české hráče Raftu.

## 📥 Instalace

### Možnost 1: RaftModding

1. Nainstaluj [Raft ModLoader](https://www.raftmodding.com/).
2. Otevři [stránku českého překladu Raftu](https://www.raftmodding.com/mods/raft-czech-translation).
3. Klikni na **Install mod** a postupuj podle pokynů.
4. Spusť Raft přes Raft ModLoader.
5. Překlad by se měl načíst automaticky při spuštění modu.

### Možnost 2: GitHub

1. Otevři [nejnovější vydání modu](https://github.com/zamazallukas02-spec/Raft-Czech-Translation/releases/latest).
2. Stáhni soubor [CzechLanguage.rmod](https://github.com/zamazallukas02-spec/Raft-Czech-Translation/releases/download/v1.0.0/CzechLanguage.rmod).
3. Nainstaluj mod pomocí Raft ModLoaderu.
4. Spusť Raft přes mod loader.

## 🧩 Kompatibilita

- **Hra:** Raft
- **Podporovaná aktualizace:** Raft Update 1.1
- **Aktuální verze překladu:** 1.0.0

## 📂 Obsah repozitáře

- `Loc.csv` — data českého překladu.
- `CzechLanguage.cs` — zdrojový kód modu.
- `CzechLanguage.csproj` — projektový soubor.
- `modinfo.json` — informace o modu.
- `CzechLanguage.rmod` — sestavený mod připravený k instalaci.
- `icon.png` a `banner.jpg` — grafika projektu.
